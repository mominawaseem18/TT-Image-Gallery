# 🖼️ TT Image Gallery

A modern and responsive **Image Gallery Web Application** built with React.js.

This project was created to practice React components, props, CSS styling, , and responsive web design.

## 🚀 Live Demo

🔗 https://tt-image-gallery.netlify.app/

## 📌 About The Project

TT Image Gallery is a React-based web application that displays a collection of images in a clean and attractive gallery layout.

The main purpose of this project was to practice building reusable React components and creating a responsive user interface.

## ✨ Features

- 🖼️ Image Gallery
- 📱 Responsive Design
- ⚛️ Built with React.js
- 🧩 Reusable Components
- 🎨 Custom CSS Styling
- 🌐 Deployed on Netlify
- ⚡ Fast and Interactive UI

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- JSX
- Netlify
